### 🔄 In-App OTA Update Channel

SkiApp includes an automated in-app update checker that queries the public GitHub Releases API without requiring user authentication:

```text
https://api.github.com/repos/RHerAle/SkiApp-Releases/releases/latest
```

When a new version is published here, users running SkiApp receive prompt update notifications and can seamlessly download and install the new APK directly.

### 🧩 Open-Source Core Engines & Components

SkiApp is built upon standalone, modular, open-source ski engineering components:

- **[RHerAle/SkiNav](https://github.com/RHerAle/SkiNav)**: High-performance 2D/3D topological ski resort routing engine (A* pathfinding, slope/lift graphs, and turn-by-turn guidance).
- **[RHerAle/SkiTracker](https://github.com/RHerAle/SkiTracker)**: GPS GNSS telemetry logger, real-time slope descent analysis, altitude profiles, and offline tracking engine.
- **[RHerAle/ski-app](https://github.com/RHerAle/ski-app)**: Complete Android application codebase and UI integration.

```text
https://api.github.com/repos/RHerAle/SkiApp-Releases/releases/latest
```

Cuando se publica una nueva compilación en este repositorio, la aplicación detecta el incremento de versión y permite descargar e instalar la actualización directamente.

### 🧩 Motores y Componentes Open-Source

SkiApp integra motores de ingeniería de esquí modulares y de código abierto:

- **[RHerAle/SkiNav](https://github.com/RHerAle/SkiNav)**: Motor de navegación y enrutamiento topológico en 2D/3D para estaciones de esquí (algoritmo A*, grafos de pistas/remontes y navegación paso a paso).
- **[RHerAle/SkiTracker](https://github.com/RHerAle/SkiTracker)**: Registrador de telemetría GPS/GNSS, análisis de descensos en tiempo real, perfiles de altitud y seguimiento offline.
- **[RHerAle/ski-app](https://github.com/RHerAle/ski-app)**: Código fuente y aplicación Android completa.
